Hi, I'm Jonas, a web developer from Vilnius. Besides web apps I build tools for two everyday chores:
testing APKs on real Androids, and keeping a fleet of repositories updated, reviewed and released.
Each one got its own organization, its own otter and its own holt.

      Every automation is a plugin configured as code: AI review of merge requests, package updates that the
      agent fixes when a pipeline breaks, vulnerability audits, browserslist and releases. Driven from a CLI,
      a web UI or a chat bot; every change lands as a merge request.<br>
